SpeakSphere - updated project notes

Changes in this version:
1. Language options now include the 28 requested languages (and only those languages).
2. Removed the source/target language search input; users choose from the visible language cards.
3. Daily learned-word hiding is keyed by source language + target language + date, so switching language pairs does not hide words learned in another pair.
4. Preserved the existing app structure and features: authentication, onboarding, learning categories, alphabet lessons, speaking, daily chat, quizzes, progress, achievements and dashboard.
5. Existing alphabet examples remain curated for Tamil/Hindi/English pairs. For other language pairs, the UI still indicates that curated alphabet lessons are not yet supplied; the language list itself does not imply complete alphabet content for every pair.

Setup:
- Extract this ZIP.
- Run npm install in speaksphere/frontend and speaksphere/backend.
- Configure backend/.env using the README, then start the backend and frontend as described there.
- Browser speech recognition/synthesis support differs by browser and language.


Language selection scope update (2026-10-10): The backend language catalogue and API now expose only these 8 languages: French, German, Korean, Chinese, Japanese, Tamil, English, and Hindi. The language picker reads this catalogue from the API, so both source and target choices use the same list. Browser speech availability depends on the device/browser.
